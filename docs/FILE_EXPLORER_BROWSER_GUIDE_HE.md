# סייר תיקיות הרשת — מדריך קצר

סייר הקבצים פועל ישירות ב־Chrome או Edge, במצב קריאה בלבד. שמות קבצים
ומטא־דאטה אינם נשלחים לשירות תיווך.

## חיבור ראשון

1. פתחו קישור לתיקיית רשת מתוך Site Builder.
2. העתיקו באמצעות כפתור **העתקה** את שורש השיתוף המומלץ
   (`\\server\share`).
3. לחצו על **בחר תיקיית רשת**, הדביקו את הנתיב בשורת הכתובת העליונה של
   בורר Windows, לחצו Enter ולאחר מכן **בחר תיקייה**.
4. בחרו את שורש השיתוף — זו האפשרות המומלצת. כך ניתן לנווט כלפי מעלה עד
   לשורש ולפתוח קישורים נוספים מתחת לאותו שיתוף בלי בחירה נוספת.
5. אפשר לבחור גם תיקיית ביניים או את התיקייה המדויקת. במקרה כזה הסייר
   מוגבל לשורש הצר שנבחר ואינו מציג תיקיות אב שלא ניתנה אליהן הרשאה.
6. אם מוצגות כמה התאמות אפשריות, בחרו את הקידומת שמתאימה לבחירה שביצעתם.

החיבור נשמר בדפדפן ובפרופיל הנוכחיים בלבד. חיבור לשיתוף מאפשר לפתוח קישורים
נוספים מתחת לאותו שיתוף בלי לבחור אותו מחדש.

ה־API התקני אינו מאפשר למלא אוטומטית נתיב UNC בשורת הכתובת של בורר Windows.
האפשרות `startIn` מקבלת חיבור שכבר נשמר או אחת מתיקיות המערכת המוכרות, ולא
נתיב רשת שרירותי. לכן העתקה והדבקה ביוזמת המשתמש הן התנהגות הייצור.

## חזרה לתיקייה שמורה

אם הדפדפן מבקש שוב הרשאת קריאה, לחצו על **מתן הרשאת קריאה**. אם תיקיית הרשת
הועברה או שהגישה השתנתה, אפשר להתחבר מחדש מתוך מסך הפתיחה. מנהלים יכולים
לפתוח **ניהול חיבורים** ולבחור בדיקה, חיבור מחדש או הסרה. הסרה מוחקת רק את
המיפוי השמור בדפדפן ואינה משנה דבר בתיקיית הרשת.

## שימוש בסייר

- לחיצה על תיקייה פותחת אותה.
- קובץ שניתן להציג בדפדפן מסומן **צפייה** ונפתח בלשונית חדשה.
- קובצי Office, ארכיונים וסוגים בינאריים שאינם נתמכים מסומנים **הורדה**
  ויורדים בשמם המקורי. לאחר ההורדה אפשר לפתוח אותם ביישום המותקן.
- אין דרך תקנית לפתוח Blob מקומי ישירות ב־PowerPoint. סכמת
  `ms-powerpoint:` דורשת כתובת HTTP/HTTPS נגישה ורישום פרוטוקול במחשב, ולכן
  אינה מתאימה לקובץ שנקרא מחיבור דפדפן מקומי בלבד.
- החיפוש מתחיל בתיקייה הנוכחית. האפשרות **חפש גם בתוך תיקיות משנה** מפעילה
  סריקה מוגבלת בעומק, בכמות הפריטים ובמספר התוצאות, מציגה התקדמות ומאפשרת
  ביטול.
- תיקייה ריקה היא מצב תקין.

## בדיקת קבלה ב־Windows

בדקו חיבור לשורש שיתוף, חיבור לתיקייה מדויקת, שימוש חוזר בקישור נוסף תחת אותו
שיתוף, שיתוף משרת אחר, שמות עם רווחים, שמות בעברית, תיקייה ריקה, רענון הדף
וסגירת כל הלשוניות ופתיחתן מחדש.
