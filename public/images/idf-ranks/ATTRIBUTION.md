# IDF rank insignia assets

The artwork in this directory comes from Wikimedia Commons files licensed under [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/). Local `.svg` files are copies of the original source; local `.png` files are unmodified 500-pixel renders generated by Wikimedia Commons from the named source SVG.

The original files were created by Wikimedia Commons user [Mintz l](https://commons.wikimedia.org/wiki/User:Mintz_l). The horizontal NCO variants (`rasal.svg`, `rasar.svg`, `rasam.svg`, `rasab.svg`, and `ranag.svg`) are derivative works by [Amirki](https://commons.wikimedia.org/wiki/User:Amirki).
